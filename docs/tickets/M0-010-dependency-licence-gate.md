# M0-010 Dependency licence gate and generated third-party notices
Status: todo
Effort: M
Model: Sonnet, high effort.
Depends on: M0-009

## Goal
ADR 0017 fixes a dependency licence allowlist, but nothing enforces it: today the only guard is
the CLAUDE.md rule that a new package needs an ADR 0002 row, and a row can state any licence a
reader types. Add a build step that reads the real licence of every restored package from the
lock files and fails on anything outside the allowlist, and regenerate `THIRD-PARTY-NOTICES.md`
from the same data so the hand-written file cannot drift. **This must land before M3-001**,
which is the first ticket to add a redistributed native dependency (Z3, with per-RID natives).

## Spec references
docs/adr/0017-licensing-and-ip.md (allowlist, denylist, the two standing exceptions);
docs/adr/0002-dependencies.md; docs/QUALITY-GATES.md

## Acceptance criteria (all must hold; nothing beyond them)
1. A local tool in `.config/dotnet-tools.json` resolves the licence of every package in every
   `packages.lock.json`, reading the package's own `.nuspec` or bundled licence file rather than
   a hardcoded table. The tool gets a row in `docs/adr/0002-dependencies.md` stating its own
   licence, per the CLAUDE.md rule.
2. The allowlist and the exception list live in a checked-in policy file, not in the script.
   The policy names each exception's package id, its licence, and the reason it is permitted;
   an exception without a non-empty reason is a hard error that stops the run.
3. A package whose licence is outside the allowlist and not in the exception list fails the run
   with a non-zero exit code and a message naming the package, its version and its licence.
4. The exceptions from ADR 0017 pass: `dotnet-sonarscanner` (LGPL-3.0, separate process) and
   `Microsoft.AspNet.WebApi.Core` (MS .NET Library EULA, samples only).
5. A package whose licence cannot be determined fails the run rather than being skipped. The
   failure names the package and says what was looked for.
6. `THIRD-PARTY-NOTICES.md` is generated by the tool. Running the generator on a clean tree
   produces no diff, and `build.ps1` fails if it does — the same shape as the existing
   `dotnet format --verify-no-changes` gate.
7. The generated file keeps the three sections of the hand-written one: redistributed,
   build-and-test-only, samples-only. Which section a package lands in is derived from whether
   it is a `PrivateAssets="All"` reference, a test-project reference, a local tool, or a
   `samples/` reference — not from a manual list.
8. `build.ps1` runs the gate, and CI fails on a violation.
9. `./build.ps1 -Integration` is green.

## Files
- `.config/dotnet-tools.json`
- `tools/licence-check/` (script plus policy file), following the `tools/sonar-triage/` shape
- `THIRD-PARTY-NOTICES.md` (now generated)
- `build.ps1`, `.github/workflows/ci.yml`
- `docs/adr/0002-dependencies.md`, `docs/QUALITY-GATES.md`

## Tests
Mirror `tools/check-coverage.Tests`: a test project for the policy evaluation covering an
allowed licence, a denied licence, a matched exception, an exception with no reason, and an
undeterminable licence. The notices renderer gets a snapshot test.

## Size guard
Eight files. If the tool is growing a package graph resolver, stop — the lock files already
have the full closure.

## Out of scope
- Changing any dependency. If the gate fails on something already in the tree, record it in
  Notes and stop; swapping a package is its own ticket.
- Licence checking for anything outside NuGet (npm, Docker base images).
- SBOM generation. Related, but a separate deliverable with its own format decisions.

## Notes
Candidate tools are `nuget-license` and `dotnet-project-licenses`. Neither is adopted yet;
whichever is chosen needs an ADR 0002 row and must itself be on the allowlist. If neither can
read a bundled `licenses/LICENSE.txt` (the form `dotnet-sonarscanner` uses, where the nuspec
says `<license type="file">` rather than an SPDX expression), prefer a small first-party script
over bending a tool that cannot see the real licence — a gate that silently reports "Unknown"
for the one LGPL package in the tree is worse than no gate.
